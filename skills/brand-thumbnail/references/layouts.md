# Thumbnail layout library

Choose one layout from the source material. Treat these as adaptable systems, not fixed templates.

## 1. Signal stack

Use for a direct-to-camera frame and a short contrarian hook.

- Place the person on one outer third.
- Place the headline in the opposite upper region with a clear edge.
- Emphasize one key word or one small structural device according to `thumbnail-brand.md`.
- Keep eyes, mouth, logo, and headline clear of interface overlays and crop zones.

## 2. Tension split

Use for before versus after, belief versus reality, or one state versus another.

- Divide the canvas with one decisive line, crop, or tonal shift.
- Give each side one short phrase.
- Make the contrast understandable without decorative arrows.
- Repeat a person only when the source truthfully supports two distinct states.

## 3. Proof frame

Use when a real workflow, document, product, interface, or physical artifact supplies the evidence.

- Make the real artifact the dominant supporting object.
- Crop tightly to the evidence that matters.
- Add a person only when an approved source portrait or frame strengthens the reading path.
- Do not redraw interface chrome or expose private data, credentials, or client identifiers.

## 4. Editorial close-up

Use for a personal belief, lesson, or emotionally charged moment.

- Use one strong close crop with natural texture.
- Let the face occupy roughly 45 to 65 percent of the canvas when the source supports it.
- Pair it with a compact headline and deliberate negative space.
- Avoid stickers, reaction graphics, and unsupported visual claims.

## 5. Object anchor

Use when a tool, product, document, or physical object carries the idea better than a face.

- Crop the real object as the visual anchor.
- Keep one clean text zone.
- Use labels only when they clarify real evidence.
- Avoid generic stock substitutes when the real object is available.

## Crop and type checks

Use the safe region defined in `thumbnail-brand.md`. If none is complete, do not guess that a platform crop is safe. Create and inspect a crop preview for the named destination.

For a 1080 x 1920 master, begin headline sizing around 100 to 150 px, then adjust for the typeface, subject, and line count. Use no more than three headline lines when possible. Rebalance any line that ends with a weak or isolated word.
