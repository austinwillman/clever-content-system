# Provenance and Audit Notes

## Upstream source

- Repository: https://github.com/anthonysurfermx/creator-knowledge-engine
- Audited component: `skills/kallaway-hooks`
- Upstream license: MIT
- Upstream attribution: The repository credits Kallaway's publicly shared YouTube material as the source of its frameworks.

This adaptation preserves the useful concepts while rewriting the operating instructions for Codex and the Clever Content workflow.

## Audit disposition

The upstream package contained Markdown instructions and references only. No scripts, binaries, network calls, secret handling, external writes, or destructive actions were present in the audited hook skill.

Useful mechanics retained:

- Topic clarity plus targeted curiosity
- Three-beat contrast structure
- Visual, spoken, text, and audio alignment
- Six hook archetypes
- Desire and proxy-desire framing
- Delay, confusion, irrelevance, and disinterest diagnosis
- Single-subject and single-question continuity

Material removed or corrected:

- Claims that a framework is universally proven or guarantees virality
- Unsupported causal and psychology claims
- Unverified performance figures presented as transferable evidence
- Crypto, DeFi, and LATAM-specific examples unrelated to the client system
- Rigid output rules that overrode user intent
- Instructions to use fear as the default purchase mechanism
- Instructions to write the hook before the body in every situation
- Unfinished TODO material and broad trigger language

## Validation policy

The framework source establishes provenance, not performance. Local results begin as hypotheses. Promote them only with dated, attributable evidence from the relevant account, audience, platform, and format.
